# AGENTS.md

Instructions for AI agents working in this repo.

This is a personal, curated directory of AI skills: ones the owner has seen (mostly on Instagram), wants to try, or has tried. Everything lives in `README.md` for now.

## Ground rules

- **Ask, don't assume.** Verdicts, token cost, ease of setup and notes are the owner's opinions. If you don't know one, ask. Never make it up.
- **Confirm before you commit or push.** Show the change first.
- **Link, don't copy.** Link to each skill's repo. Never copy skill files into this repo.
- **Use the official source.** Viral skills get forked and mirrored. Link the original author's repo, not a fork or a listing site.

## Adding a skill

1. Find its category section in `README.md`. If there isn't one, see [Categories](#categories).
2. Add one row to that section's table:

   ```markdown
   | [Name](https://github.com/author/repo) | One short line | 🏆 | Low | Easy: 1 command | Instagram | The catch, if any |
   ```

3. Keep rows sorted by verdict: 🏆 → ⭐ → 👎 → 👀.

## Verdicts

| Verdict | Use when |
|---|---|
| 🏆 Best in category | Tried it, loved it, ticks every box. More than one per category is fine. |
| ⭐ One of the best | Loved it, but it has a catch. Put the catch in Notes. |
| 👎 Didn't love it | Tried it, wouldn't recommend it. Put the reason in Notes. |
| 👀 Want to try | Not tried yet. Use `—` for Token cost and Ease of setup. |

## Columns

- **Skill:** the name, linked to the official repo.
- **What it does:** one line, in plain words.
- **Token cost:** `Low`, `Medium` or `High`.
- **Ease of setup:** `Easy`, `Medium` or `Hard`, plus a few words, e.g. `Easy: 1 command`.
- **Where I found it:** e.g. `Instagram`, `Medium article`. Link it when there's a link.
- **Notes:** one short line.

## Categories

Add a section only when it gets its first skill. Use these headings, in this order:

1. `## 💻 Software`
2. `## 🎨 Design`
3. `## 🌿 Lifestyle`
4. `## ✅ Productivity`
5. `## 🎬 Video Gen`
6. `## 🖼️ Image Gen`
7. `## 🧊 3D Gen`

If a skill doesn't fit any of these, ask the owner before creating a new category.
