# ai-skills

My personal directory of AI skills: the viral ones I've seen (mostly on Instagram), the ones I want to try, and my honest verdict on the ones I've tried.

## Legend

| Verdict | Meaning |
|---|---|
| 🏆 Best in category | Tried it, loved it, ticks every box |
| ⭐ One of the best | Loved it, but has a catch (e.g. token heavy) |
| 👎 Didn't love it | Tried it, wouldn't recommend |
| 👀 Want to try | Saw it, haven't tried it yet |

- **Token cost:** Low · Medium · High, meaning how much it burns in normal use.
- **Ease of setup:** how quickly it goes from install to working.
